# Digital CDS

Сервис сбора, структурирования и распространения знаний по новым технологиям для DS-сообщества и разработчиков Службы внутреннего аудита (СВА) Сбербанка. Инициатор — руководитель DS-направления (CDS).

## Language

**СВА**:
Служба внутреннего аудита Сбербанка — целевая организация и аудитория сервиса.
_Avoid_: аудит (без уточнения), IA

**CDS**:
Chief Data Science — руководитель DS-направления в СВА, инициатор и заказчик сервиса. Не путать с Clinical Decision Support.
_Avoid_: clinical decision support, chief data scientist (как должность вне контекста СВА)

**DS-эксперт**:
Аналитик данных из СВА — основной пользователь и роль в системе: ищет материалы, участвует в голосовании, создаёт .ipynb для разборов. Карточки с вопросами — после v1.
_Avoid_: data scientist (без привязки к СВА), эксперт

**Рядовой сотрудник СВА**:
Сотрудник СВА без DS-специализации — роль в системе: читает дайджест, голосует за темы, ищет в базе знаний.
_Avoid_: пользователь (слишком общо), сотрудник (без уточнения СВА)

**Админ**:
Роль CDS или делегата: управляет YAML-конфигами, утверждает финальный состав дайджеста, модерирует контент.
_Avoid_: модератор, superuser

**Автор контента**:
Пользователь с ролью DS-эксперт, готовящий разбор темы: .ipynb с демонстрацией и описанием применения в аудите.
_Avoid_: автор, контент-мейкер

**Цикл голосования**:
Двухнедельное окно, в котором каждый пользователь отдаёт один голос за тему. По закрытии окна победившая тема идёт на разбор.
_Avoid_: раунд, sprint, poll period

**Лидерборд**:
Публичный рейтинг активности пользователей на сайте (дайджесты, голосования, тесты, просмотры). Виден всем авторизованным пользователям. Запланирован после v1 (см. ADR-0001).
_Avoid_: рейтинг, dashboard, статистика (без уточнения «публичный»)

**Разрешённый домен**:
Корпоративный email-домен, с которого допускается регистрация: `@sberbank.ru` или `@omega.sbrf.ru`.
_Avoid_: whitelist, allowed domain

**FoundryModels**:
API-сервис Cloud.ru для обработки внешнего контента: транскрибация, русское резюме, авто-теги, эмбеддинги для поиска. Данные из YouTube обрабатываются через него; приложение развёрнуто на VM Cloud.ru.
_Avoid_: OpenAI, внешний API (без уточнения Cloud.ru)

**Shortlist дайджеста**:
Список кандидатов дайджеста после авто-ранжирования (топ-5), ожидающий утверждения админом в веб-UI перед отправкой.
_Avoid_: черновик, preview

**Событие активности**:
Запись о действии пользователя для статистики: просмотр материала, открытие дайджеста, голосование, поисковый запрос, время на странице. Собирается с v1, UI — после v1.
_Avoid_: event, metric, log

**Материал**:
Единица контента в системе: видео с YouTube после транскрибации, тегирования и добавления в базу. Источник для дайджеста и карточек знаний.
_Avoid_: контент, запись, видео (без контекста pipeline)

**Дайджест**:
Еженедельная email-рассылка с подборкой самых интересных материалов за период. Формируется авто-ранжированием с финальным утверждением админом. Дублируется в архиве на сайте.
_Avoid_: newsletter, рассылка (без уточнения «еженедельный дайджест»)

**Кандидат дайджеста**:
Материал, попавший в shortlist авто-ранжирования за неделю и ожидающий утверждения админом перед отправкой.
_Avoid_: черновик, draft

**Тема**:
Предмет для голосования и последующего детального разбора на встрече (раз в две недели). Может объединять несколько материалов.
_Avoid_: топик (англ.), subject

**Разбор**:
Встреча раз в две недели, на которой DS-эксперт/автор детально разбирает тему, победившую в голосовании. Сопровождается .ipynb.
_Avoid_: митинг, сессия, вебинар

**Карточка знаний**:
Markdown-файл в базе знаний, автоматически создаваемый из материала; используется для векторного поиска.
_Avoid_: документ, статья, note

**Карточка с вопросами**:
Небольшой тест (5–10 вопросов) для проверки понимания материала после дайджеста или .ipynb. Генерация через FoundryModels с ревью автора. Запланировано после v1.
_Avoid_: квиз, quiz, опрос

**База знаний**:
Хранилище карточек знаний с векторным поиском на сайте.
_Avoid_: wiki, база данных, KB

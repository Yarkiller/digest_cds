# Digest CDS

Digest CDS — статический прототип корпоративного сервиса сбора,
структурирования и распространения знаний для сотрудников СВА.

## Текущий статус

В репозитории находится выбранная UI-концепция **Concept 3 — Editorial UI**.
Прототип не является production-приложением: он фиксирует информационную
архитектуру, визуальный язык и интерактивные состояния будущего сервиса.

## Каноническая структура

```text
.
├── design-frontend/       # единственный активный статический прототип
├── docs/
│   ├── digest-cds/        # описание проекта, требования и критерии приёмки
│   ├── adr/               # архитектурные решения
│   └── agents/             # правила работы с доменной документацией
├── .scratch/digest-cds/   # рабочая спецификация проекта
├── CONTEXT.md             # доменный словарь и терминология
├── AGENTS.md              # правила работы AI-агентов
└── archive/               # исторические и сдаваемые артефакты
```

Актуальная документация находится в `docs/digest-cds/`, а исходным кодом
прототипа считается только содержимое `design-frontend/`. Архивные копии не
следует использовать как источник требований или реализации.

## Запуск прототипа

Из корня репозитория:

```bash
python -m http.server 8765
```

Открыть в браузере:

`http://localhost:8765/design-frontend/index.html`

Подробная карта экранов и правила работы находятся в
[`design-frontend/README.md`](design-frontend/README.md).

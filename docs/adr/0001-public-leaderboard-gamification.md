# Публичный лидерборд активности

**Status:** accepted — реализация после v1

В корпоративной среде СВА по умолчанию ожидают приватную статистику. Мы сознательно выбрали **публичный лидерборд**, видимый всем авторизованным пользователям, чтобы стимулировать участие в дайджестах, голосованиях и тестах.

**Considered Options:** (A) только личная статистика + сводка для админа; (B) публичный лидерборд; (D) анонимное сравнение со средним.

**Consequences:** нужны правила отображения (без чувствительных деталей), возможность opt-out стоит обсудить позже; gamification повышает вовлечённость, но может демотивировать отстающих. Не входит в v1 — статистика собирается с v1, лидерборд показываем позже.

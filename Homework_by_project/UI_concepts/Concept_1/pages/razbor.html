RAG в корпоративной среде

Разбор 14 апреля 2026 · Иван Петров · DS-эксперт

Код не выполняется — только просмотр. Notebook отрендерен из .ipynb через nbconvert.

Введение

Этот разбор демонстрирует минимальный RAG-пайплайн для поиска по регламентам СВА с использованием pgvector и FoundryModels для эмбеддингов.

Настройка окружения

pip install psycopg2-binary pgvector sentence-transformers

Индексация документов

Загружаем карточки знаний из базы, разбиваем на чанки и сохраняем эмбеддинги:

def chunk_document(text: str, size: int = 512) -> list[str]: words = text.split() return [" ".join(words[i:i+size]) for i in range(0, len(words), size)] def embed_chunks(chunks: list[str]) -> list[list[float]]: # FoundryModels embedding API return [foundry.embed(c) for c in chunks]

Гибридный retrieval

Комбинируем векторный поиск (pgvector) с полнотекстовым (PostgreSQL tsvector) для повышения recall на терминах аудита.

SELECT id, title, 0.7 * vector_score + 0.3 * ts_rank(tsv, query) AS combined FROM materials ORDER BY combined DESC LIMIT 5;

Применение в аудите

Пример запроса: «Какие процедуры применяются при проверке IT-общих элементов?» Система возвращает релевантные фрагменты с цитированием источника.

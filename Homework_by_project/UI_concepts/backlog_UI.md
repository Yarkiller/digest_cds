### C1-01 · Нет ясного value proposition для новичка СВА

| Поле | Значение |
|------|----------|
| Severity | LOW |
| Тип | UX |
| Экран | `pages/home.html` |
| Персона | `sva-junior` (Daria) |
| Вердикт прогона | PASSED (с замечаниями) |

**Описание.**  
Junior-аудитор за ~30 секунд «в целом» понял, что на странице есть голосование, дайджест и база знаний, но **не получил однострочного объяснения**, что такое Digest CDS и для кого он. Подзаголовок логотипа «СВА · DS-направление» и формулировки вроде scope «DS direction in SVA» не самоочевидны для сотрудника без DS-бэкграунда. Пользователь собирал картину продукта по кускам UI, а не считывал готовый one-liner.

**Проявление.**  
На home нет tagline / subtitle уровня: «Еженедельная подборка технологий для внутреннего аудита + голосование за тему разбора».

**Ожидание.**  
В первом viewport — бренд + одна понятная фраза аудитории СВА (не только DS-жаргон).

### C1-02 · Голосование сразу в состоянии «уже проголосовали» без объяснения механики

| Поле | Значение |
|------|----------|
| Severity | LOW |
| Тип | UX |
| Экран | `pages/home.html` (voting banner) |
| Персона | `sva-junior` |

**Описание.**  
Блок голосования на главной сразу показывает incumbent-состояние: выбранная тема «RAG в корпоративной среде» и CTA **«Изменить голос»**. Для первого визита / пользователя, который не помнит, что голосовал, не объяснены правила цикла: один голос, окно дат, что происходит после закрытия цикла. Механика вторична относительно кнопки смены голоса.

**Проявление.**  
Копирайт: «Ваш голос: … · можно изменить до 16 апреля» без краткого «как работает цикл».

**Ожидание.**  
Для не проголосовавших — CTA «Отдать голос» + 1–2 строки правил; для уже проголосовавших — явное «Вы уже выбрали X» + «Изменить».

### C1-06 · Ссылка на статью в дайджесте кликабельно ломается (BADSTRING)

| Поле | Значение |
|------|----------|
| Severity | HIGH |
| Тип | QA |
| Экран | Дайджест (переход с home → «Открыть →» → Дайджест №12) |
| Персона | `sva-senior` |
| Evidence | `locator.click: Unsupported token "BADSTRING" while parsing css selector` для ссылки на материал на 6+ шагах |

**Описание.**  
Ссылка на материал «Anomaly Detection with Isolation Forest» (с упоминанием кейсов во внутреннем аудите) содержит **переносы/невидимые пробелы в text node** якоря. Автотест и, потенциально, хрупкие селекторы/a11y-инструменты не могут стабильно кликнуть. Пользователь-агент **не смог открыть** самый релевантный для аудита материал и сжёг лимит шагов.

**Ожидание.**  
Нормализованный текст ссылок (без multiline внутри `<a>`), стабильный `href` на подготовленную статью в `material.html`, видимый focus/hover.
